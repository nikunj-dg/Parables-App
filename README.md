# Parables-App
An app to view and share Parables

## Features 
- View parables 
- Create new parables
- Correct the mistakes in prarables
- Delete parables 
- Account required to maked changes to parables 
- Create new accounts 
- Search for parables

## Backend
To start backend server, run the command from root folder
    "uvicorn backend.main:app --reload --no-use-colors"

## Frontend
To start frontend server, run the command from frontend folder 
    "npm run dev"
